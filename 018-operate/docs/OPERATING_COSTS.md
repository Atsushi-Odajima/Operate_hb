# OPERATING_COSTS.md — 運用費の見積もり

> 調査日: 2026-09-30。このセッションのネットワーク制限により各社の公式料金ページ（render.com / supabase.com / neon.com）には直接アクセスできず、**二次情報（料金比較記事、2026-09 時点）** と Anthropic の公開単価（claude-api スキル 2026-09-25 キャッシュ）で算出した。**契約前に必ず各社の公式料金ページで再確認すること**（RELEASE_CHECKLIST.md の人間確認事項）。為替は 1 USD = 150 円で概算。

## 1. 必要な構成要素
| 要素 | 必須 | 内容 |
|---|---|---|
| アプリ実行環境 | 必須 | Node.js 22 の Web プロセス 1 つ（ワーカー同居可、`RUN_WORKER=true`）。規模が大きい場合は Web と Worker を分離 |
| PostgreSQL 16 | 必須 | `pgvector` と `pg_trgm` が使えること（Supabase / Neon / Render Postgres / AWS RDS・Aurora / Cloud SQL で可）。添付ファイルも DB に保存 |
| バックアップ | 必須 | マネージド DB の自動バックアップ／PITR + Operate のテナントバックアップ（.json.gz）を暗号化ストレージへ |
| ドメイン・TLS | 必須 | 多くの PaaS は TLS 無料。独自ドメイン年 1,000〜3,000 円 |
| メール送信 | 任意 | 通知メールを使う場合（件名とリンクのみ）。SMTP/送信サービスの従量課金 |
| 外部 AI（Anthropic） | 任意 | AI を `anthropic` にした場合のみ。`local` なら追加費用なし |

## 2. ホスティング費の目安（1 顧客組織 = 1 環境を想定）

- 出典（二次情報）: Render 料金（Starter $7、Postgres Basic-256MB $6、ストレージ $0.30/GB/月、帯域超過 $0.15/GB）… frontdeskreview.com (checked 2026-09-26), deployhandbook.com, kuberns.com。Supabase（Pro $25、compute credit $10、pgvector 全プラン）… flexprice.io, automationatlas.io, frontdeskreview.com。

### DB 容量の目安（実測: TEST_REPORT.md の負荷データ）
- 文書 1 件（2 版、チャンク 3 件＋embedding）あたり約 10〜20 KB。画像・添付は実ファイルサイズがそのまま加算。
- 研修割当・受講記録・監査ログは 1 件 0.3〜1 KB。200 名 × 年 5,000 操作 ≒ 100 万監査行 ≒ 300〜500 MB/年。
- 監査ログは削除しない前提。年 1 回、容量プランを見直す。

## 3. AI 費用（anthropic 選択時のみ）
単価（USD / 100 万トークン、入力 / 出力）: Claude Opus 5.5 $4 / $20、Claude Sonnet 5.5 $2 / $10、Claude Haiku 4.5 $1 / $5。
1 回の AI 質問 ≒ 入力 2,000〜4,000 トークン（システム指示 + 根拠抜粋最大 5 件 + 質問）、出力 300〜600 トークン。

| モデル | 1 質問あたり | 月 1,000 質問 | 月 5,000 質問 |
|---|---|---|---|
| Opus 5.5（既定） | 約 $0.014〜0.028 | $14〜28 | $70〜140 |
| Sonnet 5.5 | 約 $0.007〜0.014 | $7〜14 | $35〜70 |
| Haiku 4.5 | 約 $0.004〜0.007 | $4〜7 | $18〜35 |
- SOP 下書き（入力〜30,000 文字）は 1 回 $0.05〜0.3 程度、Quiz 下書きは $0.02〜0.1 程度（Opus 5.5）。
- 制御: 組織設定の「月の予算上限（USD、既定 30）」に達すると外部 AI 呼び出しを停止（通常検索は継続）。利用者あたり回/分、組織あたり回/日の上限あり。`ai_usage` で月次の実費概算を画面表示。
- embedding はローカル計算のため **外部費用 0**。
- `local` provider（抽出型回答）は追加費用 0。

## 5. 販売価格との関係（79,800〜149,800 円）
- 小規模（〜50 名）では年間ホスティング費 3〜18 万円程度 + AI 実費。初期販売価格とは別に、**ホスティング・保守を月額で請求するか、買い手の自社環境で運用するか** を販売前に決める（RELEASE_CHECKLIST.md）。
- 性能・料金の数値は保証値ではない。広告に「◯万人対応」等と書かない。
