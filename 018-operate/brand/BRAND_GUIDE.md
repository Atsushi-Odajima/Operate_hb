# Operate ブランドガイド

このガイドは、Operate のロゴ・色・文字・言葉づかいを、販売資料・LP・画面・資料で統一するための決まりです。
迷ったときは「現場の人がスマートフォンで見て、すぐ分かるか」を基準にしてください。

---

## 1. コンセプト

| 項目 | 内容 |
|---|---|
| 名前 | **Operate**（表記は常にこの形。全角・小文字・カタカナ表記やロゴの改変はしない。読み方の補足が必要なときだけ「オペレート」と添える） |
| 1 行説明 | 会社のマニュアル・新人教育・ルール変更を、ひとつにまとめる。 |
| サブコピー | 仕事のやり方が、会社の力になる。 |
| 英語コピー | KNOWLEDGE DRIVES PEOPLE. |
| サポートコピー | ナレッジが、人を育てる。仕組みが、組織を強くする。 |
| 対象 | 従業員 5〜200 名の中小企業（CS、コールセンター、EC 運営、代理店、店舗、バックオフィス、営業、IT 運用） |
| 性格 | 誠実・明快・現場思い。派手さより「正しい最新版が、迷わず見つかる」安心感 |

### ブランドの約束
- **最新版だけを、正しい人に。** 承認済みの最新版を、見るべき人にだけ届ける。
- **人に依存しない仕事。** 仕事のやり方を会社の資産として残す。
- **誇張しない。** できないこと・保証しないことは、はっきり書く。

## 2. メッセージ

### 困りごと（必ずこの 3 つを、この文言で使う）
1. 古いマニュアル、危険です⚠️
2. “それ、○○さんしか分からない”をなくす。
3. 新人に同じ説明、何回していますか？

### 利用シーン（4 つ）
| シーン | 一言 |
|---|---|
| 業務の標準化 | 誰がやっても同じ品質に。手順を 1 ステップずつ。 |
| 新人教育 | 読む・学ぶ・テストするを、期限つきで届ける。 |
| 社内ルールの周知 | 重要な変更を、誰が読んだかまで確認。 |
| AI 社内検索 | 承認済みマニュアルだけを根拠に、出典つきで答える。 |

### 主な搭載機能（5 つ）
1. ドキュメント・Version 管理
2. 研修・テスト
3. 権限・承認管理
4. AI ナレッジ検索
5. 監査・レポート

## 3. ロゴ

### 構成
- **マーク**：分割された「O」のリング。リングを斜めのすき間（「/」の向き）で切り、
  「仕事のやり方が次の人へ受け渡される」動きを表す。オリジナルのベクター図形。
- **ワードマーク**：「Operate」。Plus Jakarta Sans ExtraBold（SIL Open Font License 1.1）の字形を
  アウトライン化したもの。フォントを持っていない環境でも同じ形で表示される。
- **グラデーション（マーク）**：左上から右下へ `#22D3EE`（シアン）→ `#2563EB`（ブルー）→ `#1E3A8A`（ディープブルー）。
  ダーク背景用は `#67E8F9` → `#3B82F6` → `#2563EB`。
- ワードマークの色：明るい背景では `#0B1A33`（ネイビー）、暗い背景では `#FFFFFF`。

### ファイル（brand/ フォルダ）
| ファイル | 用途 |
|---|---|
| `logo-horizontal.svg` | 横組みロゴ（マーク＋ワードマーク）。明るい背景用。基本はこれを使う |
| `logo-horizontal-dark.svg` | 横組みロゴ。暗い背景用 |
| `logo-mark.svg` | マークのみ。明るい背景用（アイコン・小さな場所） |
| `logo-mark-dark.svg` | マークのみ。暗い背景用 |
| `wordmark.svg` | ワードマークのみ（色は周囲の文字色に従う `currentColor`） |
| `favicon.svg` / `favicon.ico` | ブラウザのタブ用（小さいサイズ向けにリングを太く、すき間を広く調整） |
| `app-icon-192.png` / `app-icon-512.png` | PWA のアプリアイコン（白背景） |
| `app-icon-maskable-512.png` | Android のマスク用アイコン（余白を広く取り、円形に切り抜かれても欠けない） |
| `app-icon-dark-512.png` | 暗い背景（`#0B1A33`）のアプリアイコン |
| `apple-touch-icon.png` | iPhone / iPad のホーム画面用（180×180） |
| `og-image.png` | SNS・リンク共有用の画像（1200×630） |
| `brand-board.png` | ブランドボード（1 枚でブランドを説明する画像。第 9 章） |

### アイソレーション（周りの余白）
- ロゴの周囲には、**マークの直径の 1/2 以上**の余白を取る。ほかの文字・図形・画像の端を入れない。

### 最小サイズ
| 種類 | 画面 | 印刷 |
|---|---|---|
| 横組みロゴ | 高さ 24px 以上（幅 約 100px 以上） | 幅 25mm 以上 |
| マークのみ | 16px 以上（16〜32px は `favicon.svg` を使う） | 6mm 以上 |

### してはいけないこと
- 縦横比の変更、回転、傾け、影・縁取り・光彩などの効果を付ける
- グラデーションの色・向き・順番を変える、単色の別の色に塗り替える
- リングのすき間をふさぐ、向きを反転する
- ワードマークを別のフォントで打ち直す、文字間を詰める・広げる
- 写真や柄の上に、読みにくい状態で置く
- 「Operate」の前後に言葉をつなげて 1 つのロゴのように見せる

## 4. カラー

### 基本色
| 名前 | HEX | 用途 |
|---|---|---|
| ネイビー | `#0B1A33` | 見出し・ロゴの文字・本文の濃い文字 |
| テキスト | `#0F172A` | 本文 |
| ブルー（プライマリ） | `#1D4ED8` | 主なボタン、リンク、選択中の状態 |
| ブルー 600 | `#2563EB` | グラデーションの中間色、ホバー |
| シアン（アクセント） | `#22D3EE`（ロゴ）／`#06B6D4`（画面） | アクセント。面積は小さく |
| ディープブルー | `#1E3A8A` | グラデーションの終点 |
| 背景 | `#FFFFFF` / `#F6F8FB` | 画面・資料の背景 |
| 線 | `#E2E8F0` | 区切り線・枠 |
| 補助テキスト | `#475569` | 説明文・注記 |

### 意味を持つ色（状態）
| 意味 | 文字色 | 背景色 | 例 |
|---|---|---|---|
| OK・完了 | `#047857` | `#ECFDF5` | 公開中、修了、確認済み |
| 注意 | `#B45309` | `#FFFBEB` | 修正依頼、機密、まもなく期限 |
| 危険・期限超過 | `#B91C1C` | `#FEF2F2` | 期限超過、廃止、極秘 |
| 情報 | `#1D4ED8` | `#EFF6FF` | レビュー中、社内限定 |

**必ず文字ラベルと一緒に使う。** 色だけで状態を表さない（色の見え方に個人差があるため）。
例：赤い丸だけ ✕ → 「期限超過」の文字＋赤 ○

### グラデーション
- `linear-gradient(135deg, #22D3EE 0%, #2563EB 55%, #1E3A8A 100%)`
- 使ってよいのは **ロゴ・CTA（行動をうながすボタン）・小さなアクセント** のみ。
- 背景全面・本文の文字・表には使わない。

## 5. タイポグラフィ

| 用途 | フォント |
|---|---|
| 画面（英数字） | Plus Jakarta Sans（SIL OFL 1.1） |
| 画面（日本語） | 端末の標準フォント：ヒラギノ角ゴシック（Hiragino Sans）、Noto Sans JP、Yu Gothic UI、メイリオ |
| PDF（SOP・研修完了証） | Noto Sans JP（SIL OFL 1.1）を埋め込み |
| ロゴ | Plus Jakarta Sans ExtraBold をアウトライン化（打ち直さない） |

- 本文 15px 前後（スマートフォンでも 14px 未満にしない）、行間 1.6〜1.7。
- 見出しはネイビー、太字。1 画面に大きな見出しは 1 つ。
- 数字・版番号（v1.0、v2.0）は英数字フォントで表記。

## 6. UI（画面）のルール

- 背景は白または明るいグレー（`#FFFFFF` / `#F6F8FB`）。暗い背景の画面は作らない（アイコン・資料の一部を除く）。
- グラデーションはロゴ・CTA・アクセントのみ。
- 状態は **色＋文字ラベル** で表す（バッジに「公開中」「期限超過」などの文字を必ず入れる）。
- 押せる場所は 44px 以上の高さ。現場のスマートフォン操作では大きなボタン（「次へ」「確認しました」）を使う。
- アイコンは線の太さをそろえたシンプルな線画。絵文字はコピーの一部（⚠️ など）を除き多用しない。
- 人物写真は使わない。ピクトグラム・イラスト・実際の画面キャプチャを使う。
- AI に関する表示には「AI」の印を付け、人の確認が必要なことを明記する。

## 7. 言葉づかい（コピーのルール）

1. **やさしい言葉を先に、専門用語はあとに。** 専門用語を使うときは、すぐにかっこで説明する。
   - 例：「SOP（誰がやっても同じ品質になる標準作業手順書）」「PWA（ホーム画面に追加してアプリのように使える仕組み）」
2. **名前は常に「Operate」。** 「オペレート」は読み方の補足としてのみ。
3. **根拠のない表現を使わない。**
   - 「資格」（研修完了証は社内の完了記録であり、公的な資格ではない）
   - 「認証を保証」「ISO 準拠を保証」「法令対応を保証」
   - 「100万人対応」など、測定していない規模の表現
   - 「AI が正しく答えます」「絶対」「完全」などの断定
4. **必ず添える注記**（該当する内容を書くとき）
   - 監査：法令・規格への準拠を自動的に保証するものではありません。
   - 確認：「確認しました」は読んだことの記録で、理解の証明ではありません。
   - AI：AI の回答は間違えることがあります。根拠のマニュアルを確認してください。
   - 価格：想定価格。最終的な価格・契約条件は販売者が定めます。
5. **文体**：です・ます調。1 文は短く（40 文字前後）。主語は「会社」「チーム」「あなた」。
6. **数字は事実だけ。** 性能値はテスト環境での測定値であることを明記する。

## 8. 表記の統一

| 使う | 使わない |
|---|---|
| Operate | OPERATE、operate、オペレイト |
| マニュアル／手順書（SOP） | ドキュメント類（説明なしの「ドキュメント」多用） |
| 承認 | 決裁（社内規程の文脈以外） |
| 公開中／下書き／廃止 | Published／Draft／Retired（画面・資料では日本語） |
| 外部メンバー | ゲスト、パートナーユーザー |
| 研修完了証 | 資格証、認定証 |
| 端末に保存 | ダウンロード（オフライン保存の意味で） |

## 9. ブランドボード（`brand/brand-board.png`）

ブランドを 1 枚で伝える画像。販売ページ・提案資料の冒頭、社内共有に使う。

### 情報の順番（上から、または左上から）
1. **ロゴ**（`logo-horizontal.svg`）
2. **1 行説明**：会社のマニュアル・新人教育・ルール変更を、ひとつにまとめる。
3. **困りごと 3 つ**（第 2 章の文言のまま）
4. **利用シーン 4 つ**：業務の標準化／新人教育／社内ルールの周知／AI 社内検索
5. **主な搭載機能 5 つ**：ドキュメント・Version 管理／研修・テスト／権限・承認管理／AI ナレッジ検索／監査・レポート
6. **PWA アイコン**（`app-icon-512.png` など。ホーム画面に置いたときの見え方）

### 作り方のルール
- 人物写真は使わない（ピクトグラム・イラストのみ）。
- 情報量は以前のボードの **約 2/3** に絞る。1 項目は見出し＋1 行まで。
- スマートフォンで画像全体を表示しても、困りごと・シーン・機能の文字が読めること。
- 背景は白。グラデーションはロゴとアクセントのみ。状態色は使わない（使う場合は文字ラベル付き）。
- 余計な数字・受賞歴・根拠のない表現を入れない。
